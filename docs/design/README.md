# Design-grunnlag fra Claude Design

Eksport fra Claude Design (16.09.2026), tatt vare på som referanse for
nettstedet. Dette er prototyper, ikke produksjonskode — den faktiske
forsiden ligger i `website/`.

- `chats/chat1.md` — samtalen med designassistenten. Her står ønskene og
  beslutningene (mørk bakgrunn, tiårspaneler 2020 → 1960, portrettrotasjon).
- `Ransve Forside.dc.html` — forsiden slik den ble vedtatt. Implementert i
  `website/src/pages/no/index.astro`.
- `Ransve Tidslinje.dc.html` — de tre tidligere tidslinjeforslagene (1a, 1b, 1c).
- `support.js` — kjøretøyet prototypene trenger for å vises i nettleser.
- `assets/`, `uploads/` — bildene prototypene viser til.
- `HANDOFF.md`, `github.md` — overleveringsnotater fra Claude Design.
